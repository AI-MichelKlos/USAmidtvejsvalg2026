# Valg USA 2026

Interaktivt delstatskort med senatsvalg og guvernørvalg samt befolkningstal 2025 og socioøkonomiske nøgletal fra ACS 2020-2024. Alle 50 delstater er indeholdt i `data/states.json`.

**Bemærk:** Dette er en rekonstruktion af det offentligt viste valgkort fra 31. oktober 2026, ikke den oprindelige kildekode fra ChatGPT Sites. Særligt detaljerede distriktskort og kandidater til Repræsentanternes Hus er ikke reproduceret. Ingen live-valgresultater.

Oprindeligt kort: https://valgkort-usa-2026-michel.danske-a-kas-7580.chatgpt.site/

For at udgive på GitHub Pages: Åbn **Settings > Pages > Build and deployment**, og vælg **GitHub Actions**. Projektet har et workflow i `.github/workflows/pages.yml`.

Forventet publiceringsadresse: https://ai-michelklos.github.io/USAmidtvejsvalg/

Kilder og kandidatkilder følger `data/states.json`. Indbyggertal er fra Census 2025; andele og medianindkomst er fra American Community Survey 2020-2024 (2024-dollar).
